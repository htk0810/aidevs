# 09 통합 평가 시나리오

| 분류 | 입력 또는 행동 | 기대 결과 |
|---|---|---|
| 정상 | 8월 부산 2박, 성인 2명, 예산 50만 원 | 승인 대기 |
| 정보 부족 | 부산 여행을 준비해줘 | 누락 정보 요청 |
| Tool | 부산 호텔을 찾아줘 | `search_hotels` 선택 |
| Tool 없음 | 안녕하세요 | Tool 선택 없음 |
| RAG | 숙소 당일 취소 정책 | 정책 문서와 출처 반환 |
| 근거 없음 | 여권 분실 정책 | 근거 없음 표시 |
| Memory | 대중교통 선호 저장 후 실행 | 본인 Memory만 사용 |
| 승인 | 본인 예약 요청 승인 | `completed` |
| 거절 | 본인 예약 요청 거절 | `rejected` |
| 소유자 | 다른 사용자로 승인 | 409 차단 |
| 중복 | 완료된 요청을 다시 승인 | 409 차단 |
| Allowlist | `delete_database` 실행 | 403 차단 |
| 평가 | 기본 시나리오 실행 | 5개 통과 |

실패한 시나리오는 최종 문장만 보지 않고 Trace에서 처음 실패한 Node와 검사 항목을 확인합니다.
