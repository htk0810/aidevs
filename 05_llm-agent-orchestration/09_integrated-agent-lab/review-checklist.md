# 09 최종 리뷰와 디버깅 체크리스트

Agent가 실행된다는 사실만 확인하지 않고, 재현 가능한 입력·기대 결과·Trace를 사용해 전체 흐름을 점검합니다.

## 1. 문제 재현 정보

- [ ] 실행한 Backend가 Python인지 LangGraph인지 기록했습니다.
- [ ] 사용한 실행 명령과 환경 변수를 기록했습니다.
- [ ] `APP_MODE`, Provider, 저장소 모드를 기록했습니다.
- [ ] 입력 데이터와 기대 상태를 기록했습니다.
- [ ] 실제 상태와 오류 메시지를 기록했습니다.
- [ ] `trace_id`와 실행 Trace를 함께 확인했습니다.

```text
실행 명령:
Backend:
APP_MODE:
Provider:
입력:
기대 결과:
실제 결과:
오류 메시지:
trace_id:
```

## 2. Agent 동작

- [ ] Tool 선택과 Tool 실행이 분리되어 있습니다.
- [ ] Tool 인자는 Pydantic Schema로 검증합니다.
- [ ] 허용된 Tool만 실행합니다.
- [ ] 정보가 부족하면 임의 실행 대신 추가 정보를 요청합니다.
- [ ] 반복에는 최대 횟수와 종료 조건이 있습니다.
- [ ] Python과 LangGraph Backend가 같은 API 계약을 사용합니다.

## 3. RAG와 Memory

- [ ] RAG 답변에 근거 문서와 출처가 있습니다.
- [ ] 근거가 없으면 모른다고 답합니다.
- [ ] 사용자별 Memory가 격리됩니다.
- [ ] 비밀번호·API Key·결제 정보를 Memory에 저장하지 않습니다.

## 4. 승인과 안전

- [ ] 변경 작업은 승인 전에 실행되지 않습니다.
- [ ] 실행 소유자만 승인하거나 거절할 수 있습니다.
- [ ] 거절된 요청은 변경 결과를 만들지 않습니다.
- [ ] 완료된 요청을 다시 승인해도 중복 실행되지 않습니다.
- [ ] Prompt의 지시보다 코드의 allowlist와 소유자 검사를 우선합니다.
- [ ] 실제 예약·결제·환불은 수행하지 않습니다.

## 5. 평가와 회귀

- [ ] 정상·정보 부족·차단·거절 시나리오가 있습니다.
- [ ] 기대 Tool과 실제 Tool을 비교합니다.
- [ ] 기대 상태와 실제 상태를 비교합니다.
- [ ] 실패한 검사의 첫 Trace 위치를 찾았습니다.
- [ ] 수정 전 기준 결과와 수정 후 결과를 비교했습니다.
- [ ] 테스트가 기본 Mock 모드에서 네트워크 없이 반복됩니다.

## 6. AI 도구에 리뷰를 요청할 때

전체 저장소를 설명 없이 전달하지 않고 다음 정보만 필요한 범위에서 제공합니다.

```text
목표
실행 환경과 명령
최소 재현 입력
기대 결과와 실제 결과
오류 메시지
관련 Schema
필요한 Trace 구간
집중해서 검토할 질문
```

API Key, Access Token, 비밀번호, 실제 개인정보, 전체 `.env` 파일은 AI 도구에 전달하지 않습니다.
